# Интерфейс инвентаризации

Общий источник: prilavok-pos-ipad, c40f467. Android синхронизирован штатным scripts/sync-pos-assets.py.

В блоке товаров добавлен фильтр категорий (включая «Без категории»), совместимый с поиском. Скрытие строк сохраняет отмеченные товары, сохранение настроек учитывает все выбранные строки. Пустая выдача обозначается сообщением.

Отдельный Android-блок отменённых пересчётов удалён. Отменённые записи отображаются в общей истории в существующем порядке со статусом «Отменена», количеством сохранённых фиксаций и незавершённых строк, данными фиксаций. Формат хранения, сохранение остатков при отмене и блок «График» не изменялись.

Добавлены проверки пересечения поиска и категории, сохранения выбора скрытых строк и единой истории. Локально тесты/линт/сборка не запускались согласно AGENTS.md; проверки и подписанный APK выполняет Actions. Проверка на физическом планшете остаётся за пользователем.

Выбор категории приведён к виду раздела «Товары»: горизонтальные кнопки категорий с выделением активной, включая «Все». Используются те же общие классы оформления. Переключение не перерисовывает список и сохраняет поиск и отметки; категории прокручиваются горизонтально.

## Экран активного пересчёта
Общий источник: 2d4735f. Товары объединены по текущим категориям каталога с числом строк в заголовке, отсутствующая категория обозначена «Без категории». Порядок товаров внутри группы и содержимое черновика сохранены. Строки уплотнены, метаданные фиксации размещаются в строку, подпись «Факт» рядом с полем ввода. Кнопки экрана округлены до 999px, элементы ввода и действия сохраняют высоту не менее 44px. На узких экранах ввод переносится под название. Обработчики фиксации и отмены не менялись.
Добавлен регрессионный сценарий смешанных категорий, фиксаций, привязки подписи поля, неизменности черновика и прав сотрудника. Локальные тесты и сборка не запускались; проверка через Actions, визуальная проверка на планшете остаётся необходимой.
