# Подмена окна отложенных чеков при запуске

Причина: notification-native.js загружался после модуля parked-orders.js и заменял openParkedModal старой разметкой. Ранее проверялись ресурсы APK и изолированный модуль, но не эта итоговая подмена при запуске. Очистка данных/переустановка для исправления не требуется.

Источник 0d874ad: удалён дублирующий renderer из notification-native.js. Действия готовности WEB-заказа добавляются к общей плитке через hook parkedWebReadyMarkup, удаление сохраняет подтверждение. Android-диагностика проблемных резервов вставляется в отдельное место после заголовка. Компактная сетка, крестик и контур урны теперь используются в конечном runtime.

Добавлены регрессионные проверки общей части и Android-порядка загрузки: модуль → диагностика резервов → совместимость WEB → уведомления → совместимость WEB. Проверяются сохранение renderer, плитки, крестик, WEB-действия, подтверждение удаления и предупреждения о запасах. Локальные JS/JVM-тесты, lint и сборка не запускались согласно AGENTS.md. Actions и физическая проверка ожидаются.
