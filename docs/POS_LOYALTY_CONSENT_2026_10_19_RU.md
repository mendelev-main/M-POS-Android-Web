# Участие в лояльности на кассе

Общий источник: mendelev-main/prilavok-pos-ipad a98c031 (web-source-manifest.json содержит полный SHA). Android синхронизирован штатным sync-pos-assets.py. Kotlin, package и ключ подписи не менялись.

Новая опция после создания клиента открывает отдельное оформление добровольного личного согласия. Android сохраняет её выбор в адаптере телефонного ввода. У существующего клиента без участия кнопка доступна в заказе и административной карточке. Карточка различает отсутствие участия и отсутствие активных программ, обновляется после отправки начисления. Telegram для согласия на кассе не требуется; сотрудник открытой смены подтверждает получение согласия и сверку телефона.

Исправления снимка участия, быстрого расчёта, неизвестного офлайн-статуса и результата skipped находятся в общем JavaScript. Существующие согласия и известные версии в очереди не заменяются. Обычная офлайн-продажа сохраняется. Исторические пропущенные чеки не исправляются автоматически.

Тесты написаны; JS/JVM/lint/APK локально не запускались согласно AGENTS.md. GitHub Actions и проверка на физическом планшете на момент коммита ожидаются. Приёмка: новый клиент с согласием, новый без согласия, подключение существующего, две пиццы, повторная отправка, быстрый расчёт, офлайн, возврат и отзыв участия. Новое участие требует связи с обновлённым backend и миграцией 008.
