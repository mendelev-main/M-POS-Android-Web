# Фиксированная горизонтальная ориентация

MainActivity: android:screenOrientation изменён с fullSensor на landscape. Приложение запрашивает одну фиксированную горизонтальную ориентацию, без реакции на поворот датчика. Изменение только в оболочке Android, общий web runtime остаётся на 2d4735f63b198e4720fedef9bcc778b89726477f.

targetSdk остаётся 35. Системные окна выбора файлов/фото и другие приложения имеют свои правила ориентации. В многооконном режиме и при переопределении ориентации производителем применяются ограничения Android. При будущем повышении targetSdk до 36 требуется повторная проверка правил больших экранов Android 16.
Источник: https://developer.android.com/guide/topics/manifest/activity-element#screen

Локальные тесты, lint и сборка не запускались согласно AGENTS.md. Проверки и подписанная сборка — через GitHub Actions. Физическая приёмка: запуск из вертикального положения, поворот планшета на 90/180 градусов, сворачивание/возврат; экран приложения должен оставаться в фиксированной горизонтальной ориентации. На планшете пока не проверено.
