# Панель администратора Android Web — 08.10.2026

База изменения: 075625e12322a7b2de5eadc5a8a97d405ed2a22e. Пользователь явно запросил скрыть вход в панель при смене сотрудника без прав администратора и оформить панель одноцветными иконками. Это согласованное изменение представления Android, а не изменение правил доступа или финансовой логики.

android-admin.js загружается после исходных feature modules до loadAll. renderSettingsScreen получает текущую роль через исходный currentShiftEmployeeIsAdmin. Для неадминистратора вход openAdminPanel не попадает в разметку; stale settingsAdminPanel/loyaltyAdminScreen сбрасываются при смене прав. Без открытой смены вход также отсутствует. Исходный openAdminPanel продолжает проверять права, новый renderAdminPanel возвращает пустую строку для неадминистратора.

Все пять действий и названий сохранены: лояльность → openLoyaltyAdminScreen; сеть → setTab(network); реквизиты → openCompanyDetailsModal; инвентаризация → setTab(inventory); склад → openWarehousePage. Сохранены описания. Пять одноцветных stroke SVG currentColor соответствуют подарку, сети, зданию, списку пересчёта и складу. Иконки декоративные aria-hidden; названия остаются доступными. Возврат также использует SVG.

Панель использует исходные Manrope/theme variables и светлую/тёмную темы. Две равные колонки, выровненные иконки/тексты, спокойные границы, кнопки не меньше 100 px по высоте; ниже 760 px одна колонка. Focus-visible и native buttons сохраняют клавиатурную/сенсорную доступность. CSS ограничен новыми android-admin classes; основные настройки, рабочая зона и другие экраны не переоформлены.

Исходные 33 file hashes сохранены; source HTML отличается только Android imports. sync-pos-assets сохраняет подключение нового adapter. Не меняются localStorage/backup shapes, роли сотрудников, смены или действия панели.

Добавлены 3 regression tests для Actions: cashier shift + stale panels; administrator + сохранённые действия/монохромные SVG; закрытие admin shift. Локально только syntax/diff/source hashes. Локальный browser preview фактического renderer проверен визуально в светлой и тёмной темах при ширине 846 px: все пять действий и иконки видны, подписи не обрезаны.
