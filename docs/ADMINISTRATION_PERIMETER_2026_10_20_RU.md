# Индикатор административной сессии

Источник: 2939e632fa2b8843526d3b97c3f0083a1152277f.

Большая кнопка в верхней панели заменена фиолетовым контуром всего viewport: граница 3px, статическое мягкое внутреннее свечение, закруглённые углы 10px. Индикатор расположен поверх модальных окон, pointer-events:none не перехватывает касания. Для средств доступности сохранён текст статуса. Сессия, её права, закрытие и хранение не менялись. Android-платформенная логика не менялась.

Предпросмотр Android runtime на синтетических данных 1280×800 подтвердил размер контура ровно по viewport и работу кнопки открытия окна через слой подсветки. Изменение состояния индикатора проверяется в Actions. Локальные JS/JVM тесты, lint и сборка не запускались. Проверка на физическом планшете ожидается после установки APK.
