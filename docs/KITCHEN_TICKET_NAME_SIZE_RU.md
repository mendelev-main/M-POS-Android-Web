# Название и крупный шрифт кухонного заказа

В Android-макете кухонного документа (`__printDocumentType=kitchen`) первой строкой печатается название/подпись чека `orderLabel`, например «Стол 4 · Иван». Пробелы по краям убираются. Если подпись не задана, используется номер чека; если нет и номера — «Заказ».

Кухонные размеры увеличены примерно на треть на обеих ширинах бумаги:

| Элемент | 58 мм, px | 80 мм, px |
| --- | --- | --- |
| Название чека | 40 (было 30) | 44 (было 33) |
| Количество и название товара | 38 (было 29) | 42 (было 32) |
| Модификаторы и комментарии | 28 (было 21) | 30 (было 23) |
| Способ получения | 30 (было 22) | 32 (было 24) |
| Дата и время | 24 (было 18) | 26 (было 20) |

Длинные названия и комментарии переносятся штатным StaticLayout по ширине печати 384/576px. Ширина бумаги не менялась. Изменён только Android presentation model MPosReceiptLayout: расчёты, состав заказа, маршрутизация по категориям, число копий, оплаченные чеки и счета не менялись. Общий web-источник остаётся 69fc113e75aabce18ef4d18ca31809b117718d1e.

Проверки: имя имеет приоритет перед номером, fallback без названия, крупный текст на 58/80 мм, модификаторы/комментарии, прежние размеры оплаченного чека. Robolectric генерирует kitchen-named-58.png и kitchen-named-80.png для просмотра фактического растрового вывода. Физическая печать на Xprinter остаётся для приёмки после установки.
