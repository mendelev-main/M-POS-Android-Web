# Административная сессия отдельно от смены

Общий источник: 80c5d76. Синхронизация через штатный scripts/sync-pos-assets.py.

В настройках вместо версии — вход в «Администрирование». Успешный ввод существующего пароля открывает runtime-сессию, кнопка меняется на выход. Верхняя панель показывает «Администрирование активно» и ведёт к кнопке закрытия. Версия находится внутри панели администратора (включая Android-представление).

Сессия не входит в state/localStorage/sessionStorage/backup. Сворачивание сохраняет WebView и сессию; новый WebView при полном запуске требует авторизацию. Выход очищает runtime-данные авторизации, закрывает модальные окна, сбрасывает флаги прав редактирования. Изменяющие операции заново проверяют доступ при подтверждении.

Администраторы остаются в сотрудниках и исключены из выбора открытия кассовой смены; прямая попытка открыть смену администратором отклоняется. Исторические смены не переписываются. Открытая ранее администратором смена больше не выдаёт административные права. Административный вход/выход не меняет текущего кассира, смены и чеки. Продажи и движение наличных по-прежнему требуют смену.

Прежние проверки currentShiftEmployeeIsAdmin сохранены как совместимый адаптер новой проверки сессии. Настройки, товары, категории, сотрудники, складская админка, лояльность, резервные копии и принтеры используют общий доступ. Повторные парольные поля удалены из фиксации настроек товара, удаления, изменения роли, импорта и корректировок лояльности. Подтверждения удаления и явное подтверждение замены данных резервной копией сохранены. Для прежнего API корректировок лояльности пароль передаётся по существующему HTTPS контракту из памяти сессии, в хранилище не записывается.

Локальные тесты/линт/сборка не запускались согласно AGENTS.md. Регрессии: вход без смены, неверный пароль, отсутствие хранения сессии, новый runtime заблокирован, выход закрывает права, невозможность смены администратора, историческая смена не выдаёт прав, кассир сохраняется, продажа без смены запрещена, старые подтверждения после выхода блокируются. Бизнес-тесты явно используют привилегированный тестовый адаптер; авторизация проверяется на настоящей реализации с отдельным тестовым паролем.

Физическая приёмка: вход/выход без смены и при смене кассира; сетевые настройки и удаление товара без повторного пароля; сворачивание/возврат; принудительное закрытие и запуск; работа кассира после выхода из админки; версия в панели администратора. На планшете пока не проверено.
